❓ Como usar

Um guia rápido para encontrar e usar as principais funções do app Cosméticos App.

🛍️ Produtos e catálogoToque em “Ver meu catálogo” para consultar os produtos. Para cadastrar, editar ou excluir um produto, entre em Consultora.
👤 ClientesNa venda à vista, nome e telefone são opcionais. Na venda a prazo, informe nome e telefone; endereço é opcional. A primeira compra pode ser lançada na mesma ficha.
📦 PedidosUse Pedidos para consultar as vendas registradas e acompanhar os pedidos.
💳 PagamentosEscolha “Pago total” ou “Pago parcial”. No parcial, informe quanto foi pago e a data do restante.
📦 EstoqueO estoque é reduzido quando a venda é registrada. Quando estiver baixo ou zerado, o aplicativo avisa.
📖 RevistasEntre em Revistas e toque na edição para abrir os links online das marcas.
⭐ AvaliaçõesRegistre a avaliação recebida e, se quiser, peça a avaliação ao cliente pelo WhatsApp.
📤 CompartilharUse Compartilhar para enviar o link do aplicativo.
🔄 Atualizar aplicativoEntre em Atualizar aplicativo para verificar a versão publicada e recarregar o app.

🔒 Privacidade e informações legais

📋 Sobre os dados dos clientes

O aplicativo pode armazenar informações digitadas pelo usuário para controlar clientes e vendas, como nome, telefone, produtos comprados, valores pagos, valores a receber e datas de vencimento.

Nesta versão de teste, esses dados ficam armazenados localmente no dispositivo/navegador por meio do armazenamento do aplicativo. O aplicativo não envia automaticamente esses dados para a Natura, Avon ou Jequiti.

🛡️ Boas práticas de privacidade

  • Cadastre somente os dados necessários para o controle das vendas.
  • Evite compartilhar o aparelho ou o acesso ao aplicativo com pessoas não autorizadas.
  • Antes de apagar o aplicativo, faça backup dos dados caso essa função esteja disponível na versão utilizada.
  • O titular dos dados pode ter direitos previstos na LGPD, incluindo informação, acesso, correção e, nas hipóteses aplicáveis, eliminação dos dados.

Este texto é um aviso informativo para o aplicativo e não substitui uma análise jurídica ou uma política de privacidade específica para a forma como o aplicativo será utilizado.
